Why this matters

Scenario opener

Cloud sync feels like protection because files appear on multiple devices, but sync can also copy mistakes, deletions, and ransomware damage everywhere. Recovery needs a plan, not just convenience.

Core concept

Backups protect against ransomware, accidental deletion, and device loss. Version history protects against bad edits and overwrites.

Those are related but different tools. Version history helps when the file still exists and you need an older state. Independent backup helps when the live copy is missing, encrypted, or unrecoverable.

What a safe recovery setup includes

  • More than one copy of important files.
  • At least one recovery path that does not depend on the same live sync behavior.
  • Knowing where version history lives before you need it during stress.
  • Understanding that a writable backup can sometimes be damaged by ransomware too.
Common mistake

Sync is not the same as backup

Sync is designed to keep copies aligned. That is useful for collaboration, but dangerous when the change itself is the problem. If a file is deleted or corrupted, sync may faithfully spread the damage instead of protecting against it.

Exercise

Takeaway

A single copy is one accident from gone. Know where your backups are, and know how to roll back a version before you need to do it in a hurry.
