Why this matters

Scenario opener

A document feels like it lives "on my laptop," but it may also be syncing to the cloud, cached on a phone, and sitting in a shared folder other people can reach. If you do not know where a file lives, you also do not know who can touch it.

Core concept

"My computer" and "the cloud" are not separate places when sync is on. A file in a synced folder can exist in multiple locations at once, with different rules about deletion, sharing, and recovery.

This matters because safe file handling starts with location. Before deciding how to share or protect a file, you need a clear picture of whether it is local only, cloud-backed, shared, or already copied elsewhere.

The common storage patterns

Local only

The file is just on the device. If the device fails and no backup exists, the file may be gone.

Cloud with sync

The file exists locally and on a service. Changes and deletions may propagate between them.

Cloud-only

The device mainly shows a placeholder while the real file lives on the platform.

Email attachment

This creates a separate copy you usually cannot revoke once it has been sent.

What to do

Your first file-location rule

  • Before sharing a file, ask where the live copy really sits.
  • Check whether the folder is syncing to other devices you use.
  • Check whether a shared location already gives access to more people than you expected.

Exercise

Takeaway

Knowing where a file lives tells you who can read it, how changes spread, and what really happens when you move or delete it.
