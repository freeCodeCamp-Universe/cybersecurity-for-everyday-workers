Why this matters

Scenario opener

An unexpected file can look like ordinary work: invoice, scan, contract, onboarding packet. The danger is often decided before you open it, not after.

Core concept

Files are a common malware delivery method. The check is simple, but it has to happen before opening, not after.

You do not need advanced technical analysis for most day-to-day decisions. You need a small gate that catches the most common bad cases: unexpected files, mismatched file types, and documents asking to run code.

The three-step check

  1. 1
    Was this expected in the current workflow?
  2. 2
    Is the sender really who they appear to be?
  3. 3
    Does the file type match the story being told?
Important limit

Macros and archives deserve extra suspicion

Files that ask you to enable content are asking for permission to run code. Archives hide their contents until opened. PDFs can also contain links and scripts. "It is only a document" is not a safe assumption.

Exercise

Takeaway

Three quick questions before opening anything: was it expected, who really sent it, and is the file type plausible for the task.
