Why this matters

Scenario opener

Jae manages payroll, travel bookings, three vendor portals, and a benefits dashboard. They know every account should have a different password, but after the tenth login they start reusing variations because there is no realistic way to remember them all.

Core concept

A password manager removes the trade-off between security and memory by storing unique passwords for every account behind one strong master password.

Without a manager, the advice to "use a different strong password everywhere" often collapses under normal work pressure. A manager is what makes the better habit practical at scale.

How a manager changes the problem

A password manager stores credentials in an encrypted vault. In plain language, encryption means the stored data is scrambled so that someone without the right key cannot read it. The manager then fills passwords for you, which means you stop relying on memory and stop typing passwords into every login box manually.

This solves two problems at once: uniqueness becomes manageable, and long random passwords become usable because you no longer need to memorize each one.

Choosing a type

Common password manager categories

Employer-provided

Often the best first choice for work because it fits company policy and support processes.

Cloud-based

Syncs across laptop and phone. Useful when you log in from multiple devices during the workday.

Local-only

Keeps the vault on devices you control. This offers more manual control, but also more setup burden.

Important limit

The master password still matters

A manager reduces password reuse, but it concentrates importance into one master password. If you forget it and do not have a recovery method, you can lock yourself out of your vault. If it is weak, the protection of the vault is weaker too.

That is why the master password should follow Unit 2's passphrase rules, and why you should either keep a written backup in a physically secure place or use the provider's approved recovery setup.

What to do

Your first migration plan

  1. 1
    Confirm whether your employer already provides or requires a password manager.
  2. 2
    Create the vault using a strong passphrase you can recover safely if needed.
  3. 3
    Add your highest-risk accounts first: work email, payroll, finance, and any admin accounts.
  4. 4
    Use generated passwords for those accounts instead of inventing your own variations.

Exercise

Takeaway

A password manager is not a bonus or an afterthought. It is the tool that makes unique strong passwords realistic for people with real jobs and too many accounts.
